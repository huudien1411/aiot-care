# AIoT Care

Website giới thiệu đồ án **Giải pháp nhà ở thông minh an toàn và hỗ trợ người bệnh dựa trên IoT và AI**.

- Website: https://huudien1411.github.io/aiot-care/
- Mã nguồn hệ thống: https://github.com/khoudang/aiot-care
- Video demo: https://www.youtube.com/watch?v=jHro89Mn_LE

## Xem và cập nhật

Mở `index.html` để xem website. Giao diện dùng HTML, CSS và JavaScript thuần, không cần bước build.

GitHub Pages xuất bản nội dung từ nhánh `main`, thư mục gốc. Đẩy thay đổi lên `main` để cập nhật website.
